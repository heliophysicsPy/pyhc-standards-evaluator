# PyHC Standards Evaluator
Testing AI to automate evaluating PyHC packages against PyHC standards.

## Steps to Use:
1. Get [Claude Code](https://www.claude.com/product/claude-code)
2. Clone this repo
3. Run `claude` from the root dir
4. Point it to a PyHC package repo (e.g. local folder path, GitHub URL, DOI)
5. Evaluation reports get saved under `reports/`
